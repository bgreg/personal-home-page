# personal-home-page

Greg McGuirk's personal site, deployed via GitHub Pages.

## Conventions

- The canonical site URL is **https://www.gregmcguirk.com/** (with `www`).
  Use it for all absolute links: canonical tag, Open Graph, JSON-LD, sitemaps.
- Bio and page copy: plain, factual sentences; no self-praise or sales
  language; no em dashes.
- The About bio is written in third person.
